# 🇯🇵 @streetlog.kr 올인원 일본 여행·쇼핑 가이드 — 공개 버전 (잠금 없음)

> **라이브 주소 (GitHub Pages):** <https://streetlog.github.io/japan-guide/>
> `main` 브랜치에 커밋하면 1~2분 뒤 자동으로 반영됩니다. (Settings → Pages: Deploy from a branch / `main` / `(root)`)

누구나 링크만 열면 바로 쓰는 버전입니다. 비밀번호·보안 장치가 없어서 **배포가 가장 쉽습니다.**
(비밀번호 잠금 + 데이터 숨김 + 복제 방지가 필요한 경우 `streetlog-japan-guide-protected` 를 쓰세요.)

## 폴더 구성

```
streetlog-japan-guide-open/
├─ index.html      ← 화면 (CSS·JS 내장, 수정 거의 불필요)
├─ data.js         ← ★ 내용 수정은 여기서만 (장소·쇼핑 아이템·문구)
└─ tests/
   └─ ui.test.mjs  ← 동작 자동 점검 (선택)
```

## 1. 내용 추가·수정하는 방법

`data.js` 만 열어서 고치면 됩니다. `index.html` 은 건드리지 않아도 됩니다.

**맛집 · 카페 · 관광지 · 호텔 추가** — `PLACES` 배열 맨 아래에 한 줄:

```js
{ id: "tk-10", region: "도쿠시마", type: "맛집", ko: "가게 이름",
  ja: "店名", tip: "한 줄 팁", map: "店名 徳島県徳島市…" },
```

- `region` : `"도쿄"` / `"오사카·교토"` / `"후쿠오카"` / `"삿포로"` / `"나고야"` / `"다카마쓰"` / `"오키나와"` / `"미야코지마"` / `"이바라키"` / `"도쿠시마"` — 이 순서가 지역 필터 칩 순서입니다. 근교는 중심 지역으로 묶습니다(가마쿠라·가와구치코·요코하마 → 도쿄, 나라·고베 → 오사카·교토, 유후인·벳푸·구마모토·히타·모지코 → 후쿠오카, 오타루·노보리베쓰 → 삿포로).
- `type` : `"맛집"` / `"카페"` / `"명소"` / `"호텔"` — 이 값이 상단 5개 탭(쇼핑리스트 포함)을 나눕니다
- `ja` : 카드의 **일본어 복사** 버튼이 복사하는 값
- `map` : **지도 열기** 검색어 (비우면 `ja` 로 검색)
- `id` : 겹치지만 않으면 됨 (`tk-10`, `ty-04` …)

**쇼핑 아이템 추가** — `SHOPPING` 배열 맨 아래에 한 줄:

```js
{ id: "sp-13", cat: "과자·간식", name: "상품명", ja: "商品名", price: 500, memo: "한 줄 메모" },
```

- `price` : 엔(¥) 숫자만. 모르면 `null` → "현지 가격 확인" 으로 표시
- `cat` : `"의약품·건강"` / `"화장품·뷰티"` / `"과자·간식"` / `"식품"` / `"생활용품"`

**문구·링크** — `SITE` 안에서 인스타 주소, 상단 배너(면세·할인 팁), 하단 안내 문구를 바꿉니다.

## 2. 배포 (Cloudflare Pages · 무료)

### 방법 A — 폴더 그대로 올리기 (가장 쉬움, 3분)

1. <https://dash.cloudflare.com> 무료 가입 → 좌측 **Workers & Pages** → **Create** → **Pages** → **Upload assets**
2. 프로젝트 이름 입력 (예: `streetlog-japan`) → **이 폴더(`streetlog-japan-guide-open`) 통째로** 드래그 앤 드롭
   - 올릴 파일: `index.html`, `data.js` (테스트 폴더는 빼도 됩니다)
3. 배포되면 `https://프로젝트이름.pages.dev` 주소가 바로 생깁니다 → 인스타 프로필 링크에 넣기

### 방법 B — GitHub 연동 (수정할 때 자동 재배포)

1. 이 폴더를 GitHub 저장소 루트로 올립니다
2. Cloudflare Pages → **Connect to Git** → 저장소 선택
3. Build command: **비워두기**, Build output directory: **`/`** (루트)
4. `data.js` 를 고쳐서 커밋하면 1~2분 뒤 사이트에 자동 반영

## 3. 확인 방법

- 브라우저에서 `index.html` 을 그냥 더블클릭해도 동작합니다 (서버·설치 불필요).
- 자동 점검 (선택): `npm i -D jsdom` 후 `node tests/ui.test.mjs`
  → 카드 렌더링, 검색·필터, 담기, 합계, 체크리스트, 복사, 초기화까지 40개 항목을 확인합니다.
